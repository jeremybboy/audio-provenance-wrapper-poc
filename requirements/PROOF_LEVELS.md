# Proof Levels

## directly_observed
Information directly measured or captured by the system.

Examples:
- audio hash
- timestamps
- MIDI events
- exported file hash

## inferred
Information inferred from observable behavior.

Examples:
- probable source relationships
- session associations

## user_declared
Information manually declared by the user.

Examples:
- source type labels
- plugin descriptions
- sample origin claims

## externally_verified
Information verified by an external trusted source.

Examples:
- signed manifests
- externally validated metadata

## unknown_unobserved
Information the system cannot verify or observe.

Examples:
- hidden plugin state
- untracked routing
- bypassed workflows
- unverifiable upstream provenance
