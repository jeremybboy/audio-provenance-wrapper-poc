# Non Goals

This project does not attempt to:

- provide full Ableton Live provenance
- inspect hidden DAW memory
- reverse engineer plugins
- verify sample licenses automatically
- extract hidden preset state
- capture all system audio
- provide anti-piracy enforcement
- implement blockchain systems
- implement cloud synchronization
- certify ownership
- certify legal rights
- guarantee universal DAW support

## Product Philosophy
The system focuses on honest observable provenance only.

If something cannot be observed or verified, it must remain:
- unknown
- unobserved
- user declared
- inferred
